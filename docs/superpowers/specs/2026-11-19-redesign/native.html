Isolation levels and their anomalies

Most concurrency bugs that reach production are an anomaly the default isolation level permits, behaving exactly as documented.

The ladder of levels

LevelNewly prevents
SerializableAs if one at a timeWrite skew
Repeatable readOne snapshot per txnNon-repeatable read, phantom / lost update
Read committedCommon defaultDirty read
Read uncommittedSees unfinished writesNothing

Each rung up stops one more anomaly, and costs more locking or more aborted transactions.

Postgres and MySQL both default to a level that lets write skew through. Two doctors each see the other on call and both go home.
