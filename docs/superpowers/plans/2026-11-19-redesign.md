# Redesign (Momentum × Native-grade) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild every screen and shared component of Throughput in the approved Momentum × Native-grade design, with no change to content or behaviour.

**Architecture:** Tokens first: new values behind the existing token names, so every screen
shifts at once, plus new roles (`surface-3`, `correct`, per-track colour). Then the shared
primitives are restyled in place (same props) and the new ones added, all shown on a DEV fixture
page. Then each screen group is rebuilt on those primitives. The screen groups touch disjoint
files, so they can run in parallel.

**Tech Stack:** Vite 8 · React 19 · TypeScript · Tailwind 4 (`@theme inline` in `src/index.css`) · lucide-react · Vitest (node).

**Spec:** `docs/superpowers/specs/2026-11-19-redesign-design.md`. Reference mockups and the two source
direction specs (component lists, per-screen notes): `docs/superpowers/specs/2026-11-19-redesign/`
(`momentum.png|html`, `native.png|html`, `specs.json`).

## Global Constraints

- No change to content, progress model, scheduling, storage, routes, or what a screen does.
- No new npm dependencies.
- 375px floor; the page never scrolls sideways; every interactive target ≥ 44px (inline prose links and glossary terms excepted).
- Body text ≥ 16px; lesson body Newsreader 19px, line-height 1.55–1.6.
- WCAG AA (4.5:1 text) in both themes, enforced by `src/lib/contrast.test.ts`.
- `prefers-reduced-motion`: no transform/infinite animations; fades ≤ 150ms allowed.
- Fonts: Plus Jakarta Sans 400–800 (UI), Newsreader (lesson body), JetBrains Mono (code, timers) — from Google Fonts, runtime-cached by the existing Workbox rules.
- No uppercase monospace eyebrows anywhere. Eyebrows: 14px, weight 700, sentence case, in the track colour (or ink-2 with no track).
- No outlines as decoration: surfaces are filled; a border appears only where it carries meaning (a missed answer's dashed outline, a focus ring).
- Earned states always carry an icon: correct = check, wrong = x, streak/in-progress = flame / partial ring, mastered = `BadgeCheck` seal, missed = dashed outline + "Missed".
- Track colour is identity only: never on an answer state.
- `color-mix` and `backdrop-filter` get a plain fallback (`@supports not`).
- Copy is factual: no confetti, mascots, XP or guilt copy.
- Every task ends green on `npm run typecheck`, `npm test`, `npx oxlint src`, and the UI audit for its screens:
  `PLAYWRIGHT=/home/mark/projects/nanny-app/node_modules/playwright node scripts/ui-audit.cjs <paths>` (dev server on :5180, tmux `sdj-dev`).

## Review Focus

1. iPhone SE height (375×667): the floating tab bar plus the Resume dock must never cover the last control on a shell screen — Task 2 sets `pb-tabbar` from both heights; the audit runs at 667px tall.
2. A long explanation or a 12-section contents list in a bottom sheet on 667px: the sheet's large detent scrolls inside itself, focus stays trapped, Escape and drag-down close it — Task 2 fixture check.
3. Light-theme track colours used as 14px text (Architecture olive, Applied green are borderline) — `contrast.test.ts` checks every `--t-*` against `surface` and `paper` in both themes.
4. Reduced motion: goal-pip pulse, sheet slide, card flip and press-scale must all stop — the audit fails on running animations under `reducedMotion: 'reduce'`.
5. Long names (“Software design principles”, “Deep dive 1 — preventing double booking”) in chips, tiles, the compact bar and the Resume dock: wrap or truncate, never overflow — the audit's sideways-scroll check plus a fixture row of long names.

```ts
import { readFileSync } from 'node:fs'
import { contrast, cssTokens } from './contrast'
const css = readFileSync('src/index.css', 'utf8')
const TRACKS = ['foundations','principles','design-patterns','lld','core','databases','distributed','architecture','production','applied','interview']
for (const sel of [':root', "[data-theme='dark']"] as const) {
  const t = cssTokens(css, sel)
  describe(`contrast ${sel}`, () => {
    it.each(['ink','ink-2','ink-3'])('%s on paper, surface, surface-2, surface-3 ≥ 4.5', (k) => {
      for (const bg of ['paper','surface','surface-2','surface-3']) expect(contrast(t[k], t[bg]), `${k} on ${bg}`).toBeGreaterThanOrEqual(4.5)
    })
    it('primary pill text ≥ 4.5', () => expect(contrast(t['line-ink'], t.line)).toBeGreaterThanOrEqual(4.5))
    it.each(['correct','alert','streak','mastered'])('state %s as text on surface ≥ 4.5', (k) => expect(contrast(t[k], t.surface)).toBeGreaterThanOrEqual(4.5))
    it.each(TRACKS)('track %s as text on surface and paper ≥ 4.5', (id) => {
      expect(contrast(t[`t-${id}`], t.surface)).toBeGreaterThanOrEqual(4.5)
      expect(contrast(t[`t-${id}`], t.paper)).toBeGreaterThanOrEqual(4.5)
    })
  })
}
it('contrast() is the WCAG ratio', () => {
  expect(contrast('#000000', '#ffffff')).toBeCloseTo(21, 1)
  expect(contrast('#777777', '#ffffff')).toBeCloseTo(4.48, 1)
})
```
